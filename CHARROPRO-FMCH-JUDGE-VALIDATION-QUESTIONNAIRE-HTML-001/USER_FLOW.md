# Flujo de usuario

1. El entrevistador registra datos mínimos y autorización local.
2. La herramienta muestra instrucciones claras: no es examen ni regla automática.
3. Se recorre cada sección con su recorte de hoja y sus preguntas.
4. Cada cambio se guarda localmente; se puede salir y continuar después.
5. Al final, la entrevista se marca como terminada, pero sus respuestas siguen pendientes de revisión.
6. Desde la lista local se puede continuar, comparar, exportar JSON, exportar CSV o imprimir.
7. Un JSON exportado puede importarse para continuar o revisar; ante un ID existente se crea una copia.

La herramienta no realiza ningún paso de aprobación deportiva. El flujo posterior es humano: respuesta capturada, revisión, decisión autorizada y eventual implementación en un ticket separado.

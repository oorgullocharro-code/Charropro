# Guía de operación

1. Abra `tools/fmch-judge-questionnaire/index.html` en Chrome o Safari.
2. Capture solo los datos que el entrevistado autorice; teléfono y correo son opcionales.
3. Explique que no es un examen y que ninguna respuesta cambia una regla automáticamente.
4. Use el recorte visual para ubicar la parte de la hoja y pida ejemplos cuando ayuden.
5. Guarde el JSON al cerrar una entrevista; `localStorage` puede borrarse al limpiar datos del navegador.
6. Exporte CSV para revisión tabular e imprima la entrevista cuando se requiera una copia legible.
7. Para revisar FieldID y GAP, active Modo técnico con el entrevistado informado.

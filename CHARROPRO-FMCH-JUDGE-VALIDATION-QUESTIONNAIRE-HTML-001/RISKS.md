# Riesgos y límites

| Riesgo | Estado | Mitigación |
| --- | --- | --- |
| Pérdida de `localStorage` del navegador | Abierto | Exportar JSON después de cada entrevista relevante. |
| Respuesta verbal sin soporte escrito | Abierto | Mantener `PENDING_REVIEW` y solicitar evidencia institucional. |
| Respuestas contradictorias entre jueces | Abierto | Comparar visualmente; no resolver automáticamente. |
| Uso indebido como documento oficial | Mitigado | Aviso visible: herramienta de entrevista, no documento oficial FMCH. |
| Datos personales no autorizados | Mitigado | Teléfono y correo opcionales; sin envío externo; no usar datos reales de ejemplo. |
| Recorte visual malinterpretado | Mitigado | Derivado directamente del PDF original y con acceso a la hoja completa. |

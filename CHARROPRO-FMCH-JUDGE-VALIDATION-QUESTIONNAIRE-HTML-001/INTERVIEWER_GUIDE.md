# Guía del entrevistador

- Lea la pregunta sin sugerir una respuesta.
- Registre la explicación literal del juez y separe sus propias notas.
- Pregunte por casos especiales, sustituciones, controles y ejemplos numéricos cuando aparezcan.
- Marque la fuente declarada y el nivel de certeza según lo que explique la persona entrevistada.
- Si dos jueces discrepan, conserve ambas respuestas: la herramienta las marca para comparación, no decide cuál es correcta.
- No use la entrevista para aprobar cambios deportivos ni para actualizar una regla de CharroPro.
- Busque evidencia institucional posterior para cualquier respuesta verbal relevante.

# Charreada Profile Inheritance

La charreada conserva su `competitionType` y contexto operativo. La autoridad reglamentaria no se copia como una segunda fuente mutable dentro de cada charreada.

El scorer resuelve:

`tournament.ruleProfileAssignment -> tournament profile fields -> charreada competitionType -> catalogo de suertes`.

La creacion local puede reparar un padre local sin perfil mediante el fixture de Emulator. En Produccion, una charreada no eleva ni inventa asignaciones: consulta el assignment canonico del torneo.

# Phone Operator Control

La zona principal muestra suerte/fase, equipo/participante, oportunidad, estado y tiempo grande.

- LISTO: boton principal INICIAR.
- CORRIENDO: boton principal FINALIZAR y secundario PAUSAR.
- PAUSADO: boton secundario REANUDAR; el estado es visualmente explicito.
- FINALIZADO: sin reinicio sobre el mismo timer.

La orden solo se refleja como aceptada despues del read-back de Timer Authority. El historial aparece colapsado y no es seleccionable.

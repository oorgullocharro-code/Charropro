# Federation Temporal Projection

La orquestacion no cambia valores deportivos ni el mapeo documental certificado. Las consecuencias temporales siguen la autoridad FMCH vigente y se proyectan al campo `T` solo cuando la regla certificada lo exige.

No se crean columnas nuevas, no se mueven conceptos de MALOS/TOTAL y no se modifica `FMCH_2026_LIBRE 0.6.1` ni sus fingerprints.

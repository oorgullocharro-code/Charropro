# Scorer Timer Integration

El Scorer consume el mismo `currentTimerContext`, mantiene `officialTimers` para evidencia y actualiza el reloj RUNNING mediante el ticker DOM compartido. No ejecuta un render completo por tick.

La capability `apply-jineteo-timing` requiere `score`, por lo que un Juez autorizado puede confirmar la consecuencia deportiva sin recibir permisos generales de administracion.

Scoring context y Timer context pueden divergir de forma legitima durante Toro/Terna.

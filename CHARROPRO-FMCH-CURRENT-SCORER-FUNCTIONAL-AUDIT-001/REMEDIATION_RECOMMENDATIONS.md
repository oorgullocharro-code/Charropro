# Recomendaciones de remediacion

1. Crear un ticket de configuracion segura de navegador para Emulator: perfiles
   explicitos, sin fallback implicito a Produccion y sin exponer secretos. Es
   prerequisito para repetir la auditoria visual.
2. Crear un correctivo de identidad de catalogo para separar el id duplicado ttm de
   Jineteo de Toro, con migracion/compatibilidad y pruebas de activacion independiente.
3. Someter a comision/jueces la equivalencia FMCH de ML/CR frente a MD/MI/PC de Cala
   antes de renombrar o transformar campos.
4. Decidir formalmente si Coleadero requiere una cuarta fila en el modelo operativo;
   solo despues extender roster, estado, UI, score, auditoria y exportacion juntos.
5. Tratar firmas, emblemas y pie como un ticket de documento oficial, no como cambio de
   formulas deportivas.
6. Repetir este ticket completo contra Emulator con usuario local autorizado, capturas
   de cada suerte y fixtures de ensayo. No aprobar por evidencia estatica solamente.

# Rollback

## Client Rollback

Use the immutable remote backup produced immediately before deployment through
the established Hostinger terminal deployment workflow. Perform the rollback
with the existing rollback script and the recorded backup path; validate its
dry-run before any restore.

## Git Rollback

Create a normal revert of the release commit. Do not rewrite history and do not
edit the certified sporting profile or temporal policy artifacts.

## Expected Effect

Rollback removes client-side certified-policy activation, local interpolation
and enriched operator context. Official Timer records remain unchanged because
the implementation does not write display ticks or migrate Timer data.

No RTDB Rules or Firebase Functions rollback is required because neither target
is modified by this ticket.
